## 操作步骤

### 启动与账号

1. 启动客户端，确认登录/注册窗口始终先显示。
2. 验证已有账号回填字段；自动登录只在窗口显示后提交一次。
3. 验证自动登录失败时窗口仍可修改并手动登录。
4. 验证登录成功前没有本地插件服务和加载项，登录成功后才加载 `docxtool-wps-app`。
5. 验证取消、账号损坏和退出登录时只移除本项目加载项。

### 预览、排版与事务

1. 执行本机检测和识别预览，确认批注范围可回读，重复文字不会错绑。
2. 验证 TaskPane 显示中文状态，错误码只跟在“错误代码：”后。
3. 验证一键排版先取得公网授权；失败时不修改文档、不创建 Host 命令。
4. 验证正文、标题1—4、版头、落款、附件、页码和自动编号输出。
5. 验证失败、取消、重开或 finalize 失败后原文档可恢复；成功结果不因插件退出恢复。

### 版头、页码范围、Reader 与网络

1. 验证单机关版头、发文字号、签发人、直线型和五角星型分割线。
2. 验证指定页码范围按排版前分页固定，范围外内容不进入识别和排版。
3. 验证 Reader 书库、选书、删除、折叠、速度、进度、样式和图标。
4. 断开公网，确认后台不弹桌面窗口；主动排版显示中文离线提示。
5. 模拟 Host/TaskPane 离开，确认 Control 可接受后续请求。
